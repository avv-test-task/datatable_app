**Общие замечания**


При разработке я исходил из того, что мы:
- создаем минималистическое приложение;
- при этом соблюдаем базовые правила архитектуры (как для AngularJS, так и для PHP). То есть не просто голые скрипты, а с классовой структурой.
- создаем только функционал, описанный в задании, по принципу YAGNI опуская то, что не указано, как необходимое.

Исходя из этого, в базе данных вместо двух таблиц использована одна + поле для привязки строки к левой или правой таблице. Это более быстрый и атомарный вариант. Если бы требовалась разная структура для каждой из таблиц, либо еще какой-то уровень сложности на БД, имело бы смысл разделять таблицы.

Тот же подход в плане верстки и внешнего вида: используются базовые стили datatables, плюс минимальный фреймворк Water.

Чтобы не раздувать масштаб, опущена часть функционала, не описанная в задании, но необходимая в реальном client-facing проекте:
- авторизация, CSRF, rate limiting и прочее, что касается безопасности
- добавление, удаление, обновление данных (кроме position)
- сортировка, поиск в таблицах

Код отформатирован: php по `PSR-12`, JS по `John Papa Style Guide for Angular`.

**Установка**
- запустите сервер с поддержкой php. Пример конфигурации дан в `docker/nginx.conf'`
- импортируйте базу данных в sqlite (напр. sqlite3 `backend/database/database.db" < "database/init.sql`)
